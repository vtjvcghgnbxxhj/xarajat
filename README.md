# Xarajat

Oddiy xarajatlar daftari. Kundalik xarajatlaringizni buyruq satridan yozib boring va jami summani ko'ring.

## Talab

Python 3.8 yoki undan yangisi. Qo'shimcha kutubxona kerak emas.

## Ishlatish

```
python xarajat.py add 15000 "Tushlik"   # xarajat qo'shish
python xarajat.py list                  # ro'yxatni ko'rish
python xarajat.py total                 # jami summa
```

Ma'lumotlar `xarajatlar.json` faylida saqlanadi.

## Rejalar

- Xarajatni o'chirish
- Kategoriyalar (oziq-ovqat, transport...)
- Oylik hisobot

Takliflar va pull request'lar xush kelibsiz. Avval issue ochib, nimani o'zgartirmoqchiligingizni yozing.
